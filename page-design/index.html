统一方向：纸面网格

知构页面设计基线。

这一组页面预览把第一套风格应用到平台主要页面：发现、内容、编辑器、用户、搜索、排行、消息通知、文件、认证、网关、ID、运维和管理后台。评论作为文章详情页的一部分展示。

风格原则

中文阅读优先标题用衬线气质，正文用清晰无衬线，行高偏松。
主资源优先文章、正文、作者先展示；互动、presence、审计等附加信息局部加载。
任务页保持密度后台、运维、文件页不做营销式 hero，优先筛选、表格和详情面板。

页面清单

可直接打开

首页 / 发现流

推荐、最新、热门、关注、推荐作者和知识结构侧栏。

内容 / 文章详情

正文阅读、互动状态、相关阅读和文章下方评论区。

编辑器

对齐现有 EditorWorkspace，展示连续文档、格式工具、背景候选和草稿保存状态。

用户

公开主页、资料编辑、关系状态和隐私设置。

搜索 / 排行

搜索结果、筛选、热榜和趋势解释。

消息 / 通知

会话列表、通知中心、未读和可恢复操作。

文件

上传、附件库、封面选择和失败重试。

认证

登录、注册、错误恢复和游客引导。

网关 / ID

网关健康、请求追踪、ID 号段和服务状态。

运维

任务队列、修复动作、对账和告警。

管理后台

审核队列、用户管理、内容管理和审计日志。
